Statys
======

Statys provides descriptive measures, pairwise non-parametric tests, Friedman
and Iman-Davenport statistics, Nemenyi critical differences, and comparison
plots.

Statys requires Python 3.11 or newer.

Use array-like samples directly, without fitting an estimator or creating a
distribution wrapper. Statistical calculations and plotting are separate:
plotting functions return caller-owned Matplotlib figures and write files
only when an output destination is supplied.
